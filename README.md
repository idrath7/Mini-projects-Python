## 📂 Projects

### 🎯 1. Guess the Number Game

An interactive command-line game where the computer generates a random number between 1 and 100, and the player tries to guess it.

**Features**
- Generates a random number between 1 and 100.
- Accepts guesses from the user.
- Provides hints for higher or lower guesses.
- Displays a success message when guessed correctly.
- Allows the player to quit by entering `Q`.

**Run the project:**
```bash
python "Guess the Number Game!/python.py"
```

### 🔐 2. Random Password Generator

A simple Python program that generates a random 12-character password using letters, numbers, and special characters.

**Features**
- Generates a 12-character password.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Uses Python's built-in `random` and `string` modules.
- Demonstrates loops and string manipulation.

**Run the project:**
```bash
python "Random password generator/python.py"
```

**Note:** This is an educational password generator. For security-sensitive applications, Python's `secrets` module is recommended instead of `random`.
